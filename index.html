개요

RAM과 내장 메모리, 무엇이 다를까?

학습 목표: 스마트폰의 RAM과 내장 메모리(저장장치)의 역할 차이를 설명하고, 상황에 맞게 구별할 수 있다.

구분RAM내장 메모리
하는 일지금 실행 중인 작업을 잠시 올려 둠사진·영상·앱 파일을 오래 보관
전원을 끄면?내용이 사라짐내용이 그대로 남음
속도·용량빠르지만 용량은 작은 편 (8~12GB)RAM보다 느리지만 용량은 큼 (128~512GB)
부족하면?앱이 느려지거나 다시 로딩됨“저장 공간 부족” 알림, 설치·촬영 불가

풀이 방법
① 설명을 읽고 “전원을 꺼도 남는가?”를 먼저 떠올려요. 남으면 내장 메모리, 사라지면 RAM!
② “지금 하는 일을 돕는가, 보관하는가?”를 생각해요. 지금 작업이면 RAM, 보관이면 내장 메모리!
③ 상황 문제는 어떤 문제가 생겼는지(느려짐/다시 로딩 vs 저장 공간 부족)를 보고 골라요.

💡 비유: RAM = 일할 때 쓰는 책상 / 내장 메모리 = 물건을 보관하는 서랍장

4단계 · RAM · ROM · 보조기억장치(내장 메모리) 비교제출자: -

세 가지 메모리, 무엇이 다를까?

📌 주기억장치 = RAM + ROM / 보조기억장치 = 내장 메모리(저장장치)

전원을 껐다 켜도 내용이 남는지(비휘발성), 쓰고 지울 수 있는지, 속도와 용량을 중심으로 비교해요.

구분RAMROM내장 메모리(보조기억장치)
컴퓨터에서의 역할주기억장치 (작업대)주기억장치 (기본 프로그램을 담은 설명서 책)보조기억장치 (창고·서랍장)
전원을 끄면?내용이 사라짐 (휘발성)내용이 유지됨 (비휘발성)내용이 유지됨 (비휘발성)
읽기·쓰기자유롭게 읽고 쓰기 가능주로 읽기 위주, 사용자가 바꾸기 어려움자유롭게 읽고 쓰기 가능
속도가장 빠름비교적 느림RAM보다 느림
용량중간 (4~16GB 정도)매우 작음 (KB~MB 단위)가장 큼 (128GB~1TB 정도)
저장하는 내용지금 실행 중인 앱·작업부팅 프로그램 등 기기를 켜는 데 꼭 필요한 기본 프로그램사진, 영상, 앱, 문서 파일
스마트폰 예시스펙표의 “RAM 8GB”기기 내부의 부팅용 기본 프로그램 저장 칩스펙표의 “내장 메모리 256GB(UFS)”
⚠ 주의: 스마트폰 광고에서 “ROM 256GB”라고 하는 것은 보통 내장 저장공간(보조기억장치)을 가리키는 말이에요. 엄밀한 의미의 ROM은 용량이 아주 작은 기본 프로그램 저장용 메모리예요.
